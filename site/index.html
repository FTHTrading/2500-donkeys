THE SYSTEM

How It Works

A publishing protocol where every word is cryptographically anchored. No intermediaries.

Write

Author writes the manuscript. Every paragraph is SHA-256 hashed. Merkle trees built per content type. Deterministic, reproducible, canonical.

Anchor

Edition root anchored on Polygon Mainnet via verified smart contracts. IPFS pinning, cross-chain timestamps via Bitcoin (OpenTimestamps). Frozen forever.

Verify

Anyone can independently verify. No APIs, no accounts, no trust. Clone the repo, run the verifier, compare hashes. 58 checks across 2 suites.

FOR AUTHORS

Your Words, Your Proof

LPS-1 is an open standard. Any author can anchor their work on-chain with full cryptographic provenance.

Open Standard

MIT-licensed. Fork the repo, deploy your own contracts, anchor your manuscripts. Level 0 requires just one SHA-256 hash.

Immutable

Non-upgradeable contracts. No admin keys. Once anchored, the provenance chain cannot be altered by anyone — including the author.

Cross-Chain

Polygon for anchoring, Bitcoin for timestamps via OpenTimestamps, IPFS for content addressing. Multi-layer provenance by design.
