FOR AUTHORS

An Open Publishing Protocol

XXXIII is built on LPS-1 — an open standard any author can use to anchor their work with full cryptographic provenance. MIT-licensed, non-upgradeable, no intermediaries.

From a single SHA-256 hash to full multi-chain anchoring with Merkle trees, IPFS, and Bitcoin timestamps. Five compliance levels, one open standard.

Read the Protocol GitHub
L0
Hash Anchor SHA-256 of the full manuscript, stored on-chain. One transaction, one hash, permanent timestamp.
L1
Structured Anchor Merkle tree over chapters. Prove any paragraph without revealing the full text.
L3
Edition Freeze Edition frozen with a non-upgradeable contract. No admin keys. No one can alter the provenance chain — including the author.
L5
Full Stack Polygon anchoring + IPFS content addressing + Bitcoin timestamps via OpenTimestamps. 293 tests, 58 verify checks, DOI registered.
